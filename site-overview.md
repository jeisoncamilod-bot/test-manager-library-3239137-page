# Site Overview

## 1. Purpose

The Manager Library public presentation site is intended to introduce the Manager Library project and explain its purpose to visitors and stakeholders.

It provides general information about the system, its objectives, and its main areas of responsibility. It is separate from the application used by library staff to manage books, members, and loans.

## 2. Intended Audience

The public presentation site is intended for:

- **Visitors:** People who want to learn about Manager Library.
- **Library stakeholders:** People interested in the purpose and scope of the system.
- **Project team members:** People who need an overview of the project and its components.

## 3. Main Objectives

The site is intended to:

- Explain the purpose of Manager Library.
- Present an overview of the library management system.
- Describe the general capabilities covered by the project.
- Provide clear and accessible project information.
- Distinguish the public presentation site from the operational application and backend API.

## 4. Proposed Content Areas

The following content areas are proposed for the public presentation site:

### 4.1 Project Introduction

Introduce Manager Library and explain its role in supporting library management activities.

### 4.2 System Overview

Describe the system at a general level, including its focus on books, members, and loan management.

### 4.3 Main Capabilities

Provide a high-level description of the system's intended capabilities, such as book catalog management, member registration, loan processing, and reporting.

These descriptions must remain consistent with the official project specifications.

### 4.4 Project Information

Present relevant information about the project's purpose, scope, and organization.

## 5. Relationship with the Application and API

The public presentation site is distinct from the other main components of Manager Library.

- **Public presentation site:** Introduces the project and provides general information.
- **React application:** Provides the interface for operational library management.
- **Laravel API:** Handles backend operations and business rules.
- **Infrastructure:** Defines the supporting services and database environment.
- **Supporting tools:** Provide utilities and tools for development or demonstration.
